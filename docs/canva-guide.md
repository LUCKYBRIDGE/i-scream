# Canva 제작 지침

## 편집 순서

1. Canva에 `deliverables/knol-portfolio.pptx`를 가져와 16:9 프레젠테이션으로 엽니다.
2. 9장이 유지되는지 확인하고 한글 폰트가 바뀐 경우 Canva에서 사용할 수 있는 Noto Sans KR로 맞춥니다. 긴 제목, 화살표, 링크, 캡처 비율을 페이지별로 확인합니다.
3. 제출 양식에 이름·소속이 필요하면 표지에 추가합니다. 개인정보가 들어간 제출본은 개인 Canva 사본에서 관리합니다.
4. PDF로 내보내 링크와 글자 잘림을 확인하고 제출 양식에 맞는 파일 또는 보기 링크를 사용합니다.

## 디자인

- 16:9, 미색 바탕과 짙은 녹색 계열. 표지만 짙은 배경을 사용합니다.
- 본문 페이지는 왼쪽에 수업·업무 장면과 핵심 설명, 오른쪽에 그 장면을 보여주는 실제 화면을 둡니다. 캡처는 비율을 유지하고 필요한 부분을 확대합니다.
- 표지와 미술 활용 예시는 두 화면을 나란히 읽게 구성합니다. 화면 속 버튼 이름은 슬라이드 본문보다 작으므로, 핵심 단계는 본문에도 남깁니다.
- 위인 점프맵은 공개 완성본 화면과 공모전 수상 이력을 함께 배치합니다. 토의는 상황과 학생의 과업이 보이는 장면을 사용합니다.

## 원고 기준

- 제목은 도구 이름과 기능의 나열보다 교사·학생이 하는 행동으로 씁니다. 한 장에 한 가지 장면을 설명합니다.
- 놀평어의 문장 생성은 초안 단계로 표현하고 교사의 검토와 수정을 포함합니다.
- 활용 흐름은 공개 기능을 연결한 수업 예시입니다. 실제 수업 결과나 교사 후기처럼 표현하지 않습니다.
- 공개 배포와 교사 활용은 제작자가 제공한 내용으로 작성합니다. 이용자 수, 만족도, 시간 절감 등의 숫자는 증빙과 함께 쓸 수 있을 때 추가합니다.
- 공모전명·연도·상격은 공식 증빙의 표기를 따릅니다. 제작 중인 개인 프로젝트는 한 문장으로 소개합니다.
- 공개 화면이나 가상 예시를 사용합니다. 화면에서 이름, 계정, 실제 평어와 학생 작품 식별 정보를 확인합니다.

이 지침은 프레젠테이션 스킬의 화면 위계·가독성 원칙과 글쓰기 스킬의 구체적 사례·근거 중심 원칙을 이 포트폴리오에 맞게 적용한 것입니다.
